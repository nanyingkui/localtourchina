일별 일정

  1. Day 1
    이른 도착 · 천문산

    참고: 10:00 공항 미팅 → 짐 보관·11:00 점심 → 예약 시간에 맞춰 천문산. 운영 중인 케이블카·셔틀·에스컬레이터로 이동하고 천문동과 개방된 산정 길을 둘러봅니다. 17:30경 호텔 체크인 → 저녁. 비행 지연이나 입장권 시간에 따라 순서를 조정합니다.

  2. Day 2
    국가삼림공원 · 원가계·천자산

    08:00경 호텔 미팅 → 동문 → 십리화랑 소형열차 → 천자산 케이블카와 전망대 → 산중 점심 → 원가계 전망 구간 → 백룡엘리베이터 하산. 17:30경 저녁과 휴식. 매력상서 공연은 확정된 회차로 1회 관람합니다. 시내 호텔 이동 시간과 대기열을 반영해 픽업 시간을 안내합니다.

  3. Day 3
    황룡동 · 대협곡

    08:30경 호텔 출발 → 황룡동 동굴과 유람선 → 11:30경 점심 → 대협곡 유리다리·엘리베이터·잔도와 협곡 산책. 17:00경 차량 합류 후 호텔로 돌아갑니다. 미끄러운 동굴 계단과 고소 구간이 있어 이동 능력에 맞춰 진행합니다.

  4. Day 4
    체크아웃 · 공항 샌딩

    조식·체크아웃 → 항공편에 맞춰 전용 차량으로 공항 이동. 출발일 중식 포함 여부는 선택한 참고 일정과 실제 출발 시간으로 확인합니다. 마지막 날 새 호텔 숙박을 추가하지 않습니다.

  1. Day 1
    도착 · 호텔 체크인

    항공편 도착에 맞춰 공항 도착층에서 미팅 → 전용 차량으로 시내 호텔 이동 → 체크인과 휴식. 늦은 도착일에는 관광을 넣지 않습니다. 저녁식사 필요 여부는 도착 시간에 맞춰 별도 확인합니다.

  2. Day 2
    동네 산책 · 천문산

    08:40경 호텔 미팅 → 가까운 시장·동네 산책과 커피 휴식(음료 개별 결제) → 11:30경 점심 → 예약 시간에 맞춰 천문산. 천문동과 개방된 산정 길을 방문하고 호텔로 돌아와 저녁식사를 합니다. 시장 운영과 입장 시간에 따라 순서가 바뀔 수 있습니다.

  3. Day 3
    국가삼림공원 · 원가계·천자산

    08:00경 호텔 미팅 → 동문 → 십리화랑 소형열차 → 천자산 케이블카와 전망대 → 산중 점심 → 원가계 전망 구간 → 백룡엘리베이터 하산. 17:30경 저녁과 휴식. 매력상서 공연은 확정된 회차로 1회 관람합니다. 시내 호텔 이동 시간과 대기열을 반영해 픽업 시간을 안내합니다.

  4. Day 4
    황룡동·대협곡 후 공항으로

    08:00경 체크아웃, 짐은 차량에 보관 → 황룡동 → 점심 → 대협곡 → 이른 저녁 → 공항으로 바로 이동. 23:00경 항공편을 가정한 참고 배치이며, 공항에는 항공사 요구 시간에 맞춰 여유 있게 도착하도록 역산합니다. 관광을 위해 체크인 마감을 넘기지 않습니다.

    오전 천문산 · 공항 샌딩

    가능한 가장 이른 예약 회차로 천문산 → 정해 둔 하산 마감 시간까지 공항 차량에 합류 → 공항 샌딩. 14~15시 항공편은 입장 회차·동선·교통·체크인 여유가 모두 확인될 때만 적용합니다. 조건이 맞지 않으면 앞선 날로 천문산을 옮기며 당일 관람을 보장하지 않습니다.

포함 항목

시내 동급 부티크 호텔 3박·조식, 2인 1실(홀수 인원은 남는 1명 별도 객실). 한국어 가이드, 좌석 수에 맞는 차량과 기사·주차·도로비, 장가계 공항 픽업·샌딩. 일정표의 식사와 80분 마사지 1회. 호텔은 예약 가능 여부에 따라 동급으로 확정합니다.

국가삼림공원·천문산·일정에 명시한 관광지 입장권과 해당 이동시설, 매력상서 1회

불포함·별도 비용

항공·장거리 교통, 비자·여행자보험, 개인 소비, 추가 식사·주류, 객실·호텔 업그레이드, 별도 요청 관광. 다일 투어는 하루 약 10시간 안내가 기준이며 초과 일정은 사전에 합의하고 시간당 ₩20,000을 가이드에게 직접 지급합니다. 포함된 공연으로 서비스가 길어지는 날도 출발 전에 시간을 확인합니다. 1시간 미만 정산은 별도 확인합니다.

예약 조건

표시 시간은 중국 현지 시각의 참고 일정입니다. 입장권·날씨·체력과 항공편을 확인해 최종 순서를 확정합니다. 시내 기본 호텔·선택한 식사 수·차량 기준의 참고가이며, 공휴일·무릉원 숙박·실제 픽업/샌딩 시간 변경은 다시 견적합니다. 2명부터 단독 출발을 문의할 수 있습니다.
