정오 무렵 도착 · 오후 출발

  1. 정오 무렵 도착 · 오후 천문산은 확인 후

    중국 현지 시간으로 정오 무렵 도착 → 실제 도착 시각에 맞춰 공항 미팅 → 짐 보관과 점심. 이동·수속·대기 시간을 감안해 오후 입장이 가능한지 확인한 경우에만 천문산을 방문합니다. 예약한 노선과 운영 상황에 맞춰 천문동과 개방된 산정 길을 둘러본 뒤 호텔 체크인·저녁. 도착이 늦어지거나 입장이 어려우면 첫날은 호텔에서 쉬고 관광을 다음 날 이후로 조정합니다. 오전 관광이나 정해진 입장·종료 시각을 약속하지 않습니다.

  2. 국가삼림공원 · 원가계·천자산

    08:00경 호텔 미팅 → 동문 → 십리화랑 소형열차 → 천자산 케이블카와 전망대 → 산중 점심 → 원가계 전망 구간 → 백룡엘리베이터 하산. 17:30경 저녁과 휴식. 매력상서 공연은 확정된 회차로 1회 관람합니다. 선택한 호텔 이동 시간과 대기열을 반영해 픽업 시간을 안내합니다.

  3. 황룡동 · 대협곡

    08:30경 호텔 출발 → 황룡동 동굴과 유람선 → 11:30경 점심 → 대협곡 유리다리·엘리베이터·잔도와 협곡 산책. 17:00경 차량 합류 후 호텔로 돌아갑니다. 미끄러운 동굴 계단과 고소 구간이 있어 이동 능력에 맞춰 진행합니다.

  4. 체크아웃 · 공항 샌딩

    조식·체크아웃 → 항공편에 맞춰 전용 차량으로 공항 이동. 출발일 중식 포함 여부는 선택한 참고 일정과 실제 출발 시간으로 확인합니다. 마지막 날 새 호텔 숙박을 추가하지 않습니다.

  4. 황룡동·대협곡 후 공항으로

    08:00경 체크아웃, 짐은 차량에 보관 → 황룡동 → 점심 → 대협곡 → 이른 저녁 → 공항으로 바로 이동. 23:00경 항공편을 가정한 참고 배치이며, 공항에는 항공사 요구 시간에 맞춰 여유 있게 도착하도록 역산합니다. 관광을 위해 체크인 마감을 넘기지 않습니다.

포함 항목

선택한 호텔 3박·조식, 2인 1실(홀수 인원은 남는 1명 별도 객실). 한국어 가이드, 좌석 수에 맞는 차량과 기사·주차·도로비, 장가계 공항 픽업·샌딩. 일정표의 식사와 80분 마사지 1회. 선택한 호텔의 객실 가능 여부를 확인한 뒤 예약하며, 대체 호텔은 사전에 협의합니다.

국가삼림공원·천문산·일정에 명시한 관광지 입장권과 해당 이동시설, 매력상서 1회

불포함·별도 비용

항공·장거리 교통, 비자·여행자보험, 개인 소비, 추가 식사·주류, 객실·호텔 업그레이드, 별도 요청 관광. 다일 투어는 하루 약 10시간 안내가 기준이며 초과 일정은 사전에 합의하고 시간당 ₩20,000을 가이드에게 직접 지급합니다. 포함된 공연으로 서비스가 길어지는 날도 출발 전에 시간을 확인합니다. 1시간 미만 정산은 별도 확인합니다.

예약 조건

표시 시간은 중국 현지 시각의 참고 일정입니다. 입장권·날씨·체력과 항공편을 확인해 최종 순서를 확정합니다. 선택한 호텔의 실제 숙박일 3박과 해당 식사·차량 기준의 참고 견적입니다. 하루라도 요금이 없으면 상담으로 확인합니다. 픽업 시간과 최종 동선은 호텔 위치·항공편에 맞춰 안내합니다. 2명부터 단독 출발을 문의할 수 있습니다.

항공편과 날씨에 맞춰 짜는 일정

일행의 걸음과 입맛에 맞는 선택
걷는 속도와 계단이 부담스러운 구간을 미리 확인합니다. 식사는 매운맛과 향신료에 대한 선호를 듣고, 현지 음식과 편하게 드실 메뉴를 함께 제안합니다.
예약 전에 확인하는 여행비
호텔 지점과 객실, 포함된 식사와 입장권, 일행 총액과 별도 비용을 견적에서 확인할 수 있습니다. 일정에는 쇼핑 매장 방문이나 유료 선택관광이 없습니다.
