张家界，

在林间和餐桌旁聊聊天的五天。

关于这趟旅行我们的五天餐饮·住宿·费用咨询行程

连同一起旅行的人，
都记在心里的旅行。

在观景台把相机交给导游，大家一起入镜；在林间放慢脚步，到市区再亲手挑选好奇的零食。

从高处看，再到山下走看过袁家界群峰，第二天换成黄石寨的视野与金鞭溪的林间路。看景的距离、走路的感受，也随之不同。

休息时间，也有安排的理由山上的午餐、市区的一杯咖啡、下山后的按摩。在移动之间，留出坐下来休息的时间。

第1天

走过陌生的机场，
抵达我们房间的夜晚。

机场会合 → 专用车辆 → 酒店入住

走出入境大厅后

第一晚，找路的事交给我们。

核对出发前收到的会合地点及联系方式，与韩语导游见面。装好行李，乘专车前往酒店，抵达当晚不安排游览。

只确认明天早晨要准备什么。

入住后了解早餐地点、出发时间和小背包里要带什么，接着休息。同一家市区酒店住4晚，不必每天重新打包行李箱。

按较晚抵达的时间准备

根据航班及行李数量准备接机，报价单写明酒店和客房。抵达后需要较晚用餐，请提前告知；当天餐食另计。

餐饮·住宿抵达当天餐食另计
入住同一家市区酒店

步行·接送以机场、酒店接送为主。第二天早餐后出发。

第2天

曾经仰望的山峰，
来到眼前的一天。

十里画廊 → 百龙天梯上行 → 袁家界 → 天子山索道下行

上午 · 从山脚开始

先抬头看，再上山。

坐在十里画廊小火车上，找找岩石各自的形状。乘环保车到百龙天梯后，沿悬崖向上。刚才在山脚看的山，到了观景台又换了高度。

今天，
上山的路，
和下山的路，
也不一样。

乘百龙天梯上山，
坐天子山索道下山。
留些力气，
走走观景路段。

中午 · 袁家界与天下第一桥

拍好一张照片，
也看看取景框之外。

先看观景台附近的一根石柱，再沿着后方层叠的山慢慢移动视线。需要合照时，把手机交给导游即可。想多拍风景，还是把大家拍清楚，都可以说出喜欢的构图。

不用为吃午餐再下山

游览天下第一桥一带后，在山上用午餐、坐着休息，再接着看天子山风景并下山。

下午 · 从天子山下山

这一次，坐着看。

走完观景路段，坐进索道车厢。看岩石渐远、森林靠近，慢慢下山。晚上也可以翻翻彼此的照片，找出今天最喜欢的画面。

餐饮·住宿含早餐 · 午餐 · 晚餐
入住同一家市区酒店

步行·接送观景台之间有步行和台阶。含小火车、百龙天梯上行、天子山索道下行。园内交通与其他游客共乘。

第3天

看过山的轮廓，
再沿山下的水路走。

黄石寨往返索道 → 午餐·休息 → 金鞭溪

上午 · 黄石寨

从一座峰，
看到群山叠起的风景。

从南门进入，搭乘索道。在黄石寨看看近处树木外延伸的山形。走过观景路段后，也乘索道下山，再吃午餐、休息。

下午 · 金鞭溪

这一次，
也留下水声吧。

先与导游确定走到哪里、怎样返回。走到能看见水的地方，就停下来听一会儿。愿意的话，用手机录10秒声音。今天上午的风景照旁，也留下一段林间水声。

第二段散步，按大家的步调来

这一天既走黄石寨观景路段，也走金鞭溪。到入口时结合体力和剩余时间确定范围，不要求所有人统一走完全程。

餐饮·住宿含早餐 · 午餐 · 晚餐
入住同一家市区酒店

步行·接送黄石寨观景路段、金鞭溪均需步行，含往返索道。步行距离及休息点按同行人的状态说明。

第4天

从挑选的乐趣开始，
再走上天门山的路。

市区超市·咖啡 → 午餐 → 天门山 → 晚餐·按摩

上午 · 市区超市

一个熟悉的味道，一个想尝的新味道。

把不确定口味的包装拿给导游，一起看看甜味、辣度和保存方法，再选些适合分享的零食。自愿购买，费用另计。照片为金粒门商品示例，实际门店按路线确定。

含每人1杯咖啡

坐下来，
把昨天的照片，
一起分享。

热的，还是冰的？确认想喝的饮品，坐下来休息一会儿。悠闲的上午之后，吃过午餐再去天门山。

上山之前，让上午换个节奏

游览两天公园之后，留一个市区上午。按天门山门票时间前往景区，门店与咖啡路线也围绕这个时间安排。

下午 · 天门山山顶

走向风景的路，
原来是这个样子。

沿护栏行走，遇到视野开阔处就停下。走着看的画面，与站定后看的画面，交替出现。怕高请在预订前告知，先确认门票与可行路线。

这些台阶，都得爬吗？

会确认交通与扶梯路线，减轻徒步登999级台阶的负担。上下山顺序按预约门票及设施运营确定。

下山后，吃晚餐，再留80分钟休息

含80分钟足部及全身按摩。天门山等候时间较长时，可协调改到其他日期，尽量不因行程延误而压缩按摩时间。

餐饮·住宿含早餐 · 午餐 · 晚餐
入住同一家市区酒店

步行·接送天门山山顶有步行和台阶。含1杯咖啡、80分钟按摩。对高处和玻璃地面的顾虑，请在预订前确认。

第5天

山里的路，桥上的路。
直到最后，仍有不同画面。

退房 → 黄龙洞 → 午餐 → 大峡谷 → 晚餐 → 机场

上午 · 黄龙洞

昨天看山外，
今天看山里。

退房后行李装车，只带小包进入。近看灯光照到的岩石纹理，再抬头沿着形状看到洞顶。跟着导游，按大家的节奏走步道和台阶。

下午 · 大峡谷玻璃桥

照片里的桥，
这次亲自走上去。

入口处确认走法后一起过桥。看玻璃下面，还是看正前方的山，按自己的舒适程度来。在不妨碍通行的地方拍照。怕高的话，预订前先确认可调整的路线。

峡谷游览后 · 晚餐与返程

最后一个画面，
留在水边。

按预约路线游览峡谷下方风景，记住高处感受到的尺度，也记住水边看到的颜色。晚餐后直接去机场，不再绕回酒店取行李。

最后一天，从返程航班倒推

先确定计划到达机场的时间，再计入走到峡谷出口和用晚餐的时间。若是较早出境航班，会调整当天安排后说明。

行李卸下来，
再留最后一张合照。

最后一餐后前往机场。下车前检查护照、小包及座位上的物品。时间充裕的话，也可以和一路同行的导游拍张照片，好好道别。

餐饮·住宿含早餐 · 午餐 · 晚餐
晚餐后前往机场

步行·接送黄龙洞有台阶、大峡谷需步行，含玻璃桥。按晚班出境航班安排。

用餐与休息时间，也一起准备
