假期短，
先看一直想看的风景。

即使夜里抵达，
三个游览日也安排得具体。

第一天回酒店休息，第二天去天门山，第三天游森林公园，最后一天看黄龙洞和大峡谷。在短短几天里，用不同方式体验张家界的代表风景。

三个游览日

市区·天门山／森林公园／溶洞·峡谷

在同一个地方住三晚

酒店3晚／9餐／演出、按摩各1次

最后一天仍有步行路段。按晚到、23点左右返程安排，不含黄石寨、金鞭溪和芙蓉镇。

我们的四天

  1. 1抵达当晚，在酒店休息
  2. 2从市区走向天门山步道
  3. 3天子山、袁家界与晚间演出
  4. 4经过黄龙洞、大峡谷，前往机场

把喜欢的体验先选下来。
咨询时，一起聊聊怎样留出这些时间。

1天

今天的目的地，
是能好好休息的房间。

机场会合 → 专用车辆 → 酒店

明天再游览，今天先好好抵达。

抵达当晚

下飞机以后，
认路的事，交给我们。

走出入境大厅后，在提前收到的会合地点见韩语导游。装好行李，前往酒店。深夜抵达的第一天不安排游览。

入住之后

只需准备明天的小背包。

确认早餐地点和次日会合时间。导游按航班及行李数量准备车辆，预订前告知客房与床型安排。

我们提前准备。抵达后需要晚餐，请提前告诉我们。

基础费用不含抵达当天餐食，我们会按抵达时间确认可安排的用餐并告知。

餐饮·住宿抵达当天餐食另计
入住同一家市区酒店

步行·接送以机场到酒店的接送为主。第二天从市区出发去天门山。

2天

从街坊的早晨，
走到山中那扇门前。

市区超市·咖啡时间 → 午餐 → 天门山 → 晚餐

从日常的尺度，走进山的辽阔。

上午 · 从市区开始

陌生的味道，先问明白。

好奇包装上写的口味，可以拿给导游看。确认辣不辣、适不适合分享，再挑自己喜欢的。喝咖啡时坐下来休息，听听下午安排。饮品、零食费用另计。

悠闲的上午，也有安排顺序。按天门山入园时间，安排上午活动。

确认市场、门店营业情况和天门山预约时间后，调整到访顺序。不保证一定到访照片中的特定门店。

下午 · 天门山

照片里的巨大，
这次亲身感受。

在天门洞前抬起头，看看岩石之间形成的空洞。山顶沿护栏内侧行走，遇见开阔处就停一会儿。想拍合照，可以把希望的构图告诉导游。

下山后 · 晚餐与休息

第一座山留下的余韵，
坐下来，慢慢回味。

包含1次80分钟足部及全身按摩。优先考虑下山后安排，但会结合天门山等候与实际预约，协调到行程中可用的日期。

我们提前准备。上下山的方式，也先确认好。

使用预约线路的交通和扶梯，减轻爬台阶的负担。对高处或玻璃地面感到不适，请在预订前告知。

餐饮·住宿含早、午、晚餐
入住同一家市区酒店

步行·接送天门山山顶仍有步行和台阶。含门票、预约线路交通、扶梯及鞋套。

3天

这一次，和群峰
站在同样的高度。

十里画廊 → 天子山索道上行 → 袁家界 → 百龙天梯下行 → 魅力湘西

乘索道上山，坐百龙天梯下山。

上午 · 十里画廊与天子山

在小火车上仰望，
在索道里俯瞰。

坐十里画廊小火车，找找岩石各自的形状。接着乘天子山索道，刚才看到的树木渐渐来到脚下。在观景路段一起走，遇见视野开阔处就停下。

中午 · 山上用餐与袁家界

拍完照，
再多看一会儿。

在山上吃午餐、坐着休息后，再去袁家界。交替看看眼前的石柱和后方延伸的群山。把手机交给导游，负责拍照的人也能加入合影。

为什么在山上休息。不用为了吃午餐再下山。

把公园环保车和观景路段间的移动连起来准备。即使是独立成团，园内交通仍与其他游客共乘，也可能需要排队。

今天的最后一段，
坐下来，听一听、看一看。

晚餐后观看已确认的魅力湘西演出1场。这里用插画说明观演体验，并非演出实拍。

说明旅行场景的插画

晚上 · 魅力湘西

白天看岩石的形状，
夜里听音乐、看舞台。

下山用晚餐后前往剧场。坐在座位上，听音乐、看舞台上的动作；散场后聊聊最记得的画面。具体演出时间和座席条件按预约内容说明。

餐饮·住宿含早、午、晚餐
入住同一家市区酒店

步行·接送观景台之间有步行和台阶。含往返小火车、天子山索道上行、百龙天梯下行及1场演出。

4天

走过山的内部，
再穿过山间，踏上归途。

退房 → 黄龙洞 → 午餐 → 大峡谷 → 晚餐 → 机场

返程那天，也多留一个画面。

上午 · 黄龙洞

近看石头的纹理，
抬头看洞厅的高远。

退房后行李放在车上，只带小包入内。近看岩石表面，再顺着向上延伸的形态望向洞顶。台阶和步道按大家的步调慢慢走。

我们提前准备。不用再回酒店取行李。

车辆和行李提前准备好，游览后直接去机场。洞内游船按实际所订门票及现场运营确认。

下午 · 大峡谷

第一步，慢一点，
视线放在让自己舒服的地方。

看玻璃下面，还是看正前方的山，都按自己的感受来。与导游确认走法，一起过桥；在不妨碍通行的地方拍照。

从返程时间倒推。
  1. 确认航班与计划到达机场的时间
  2. 预留峡谷出口、乘车及晚餐时间
  3. 在这个范围内确定步行路段和休息点

晚上 · 晚班返程

最后一天，
仍是完整的游览日。

这套安排以23点左右出境航班为基础，溶洞和峡谷都有台阶与步行路段。若返程较早，将调整游览范围，不会缩减机场办理手续的时间来硬塞景点。

适合我们这些同行人吗？

如果航班时间不同呢？

本页按深夜抵达、最后一天23点左右出境安排。较早抵达时，重新查看天门山日期、餐次和服务时间；较早返程时，重新安排溶洞、峡谷及机场接送。不保证所有航班都适用相同价格。

适合带父母去吗？

请说明平时能走多久、上下台阶是否吃力。即使乘索道，观景台、溶洞和峡谷仍需步行。我们会按大家的体力确认休息点和可走路段。

怕高怎么办？

对天门山悬崖步道或玻璃桥有顾虑，请在预订前告知。确定门票前，会说明可行路线及省略、替换带来的费用变化。
