参考行程（中国时间）

第1天 · 古城街巷与沱江夜景

约10:00在张家界酒店集合 → 前往张家界西站，按所订车次提前候车 → 高铁至凤凰古城站 → 接驳至古城、寄存行李 → 午餐自理 → 下午游沈从文故居、万寿宫和河岸街巷 → 酒店入住 → 约17:30晚餐 → 按预约时段夜游沱江 → 约20:00返回酒店休息。具体集合时间随车次调整。

第2天 · 古城清晨与返程

酒店早餐 → 约09:00沿沱江散步、看清晨的古城 → 自由活动 → 约11:30退房 → 午餐 → 按车次提前送凤凰古城站 → 高铁返回张家界西站 → 接驳回酒店。此产品以送回张家界酒店结束；当日接续航班需另核余量。

包含项

往返高铁二等座、张家界酒店与两端车站接驳、韩语导游、凤凰含早标间1晚、第一天晚餐及第二天午餐、夜游沱江＋沈从文故居＋万寿宫套票。双人一间，奇数余下1人单独一间已计入。

不包含与边界

第一天午餐、未列明餐食和酒水、完整九景联票、游客保险、个人消费、额外客房或酒店升级。节假日使用对应房价；列车、游船和景点按实际运营与库存确认。临时增加活动或超出约定服务时段须事先协商。

独立出发与拼团

2人起可独立出发。也可申请同日同线拼团；达到4位付费游客并落实高铁座位、导游、接驳和客房后确认。页面显示的拼团优惠为成团参考，客服确认总人数后给出书面价格；未成团可协商改期或按独立出发核价。加入清单不代表预订成功。
