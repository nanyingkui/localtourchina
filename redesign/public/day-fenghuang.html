1일차 · 고성 골목과 퉈장의 밤

약 10:00 장가계 호텔 미팅 → 예약 열차 시간에 맞춰 장가계서역으로 이동, 여유 있게 대기 → 고속철도로 봉황고성역 → 고성으로 이동해 짐 보관 → 점심 개별 식사 → 오후 선충원 생가·만수궁·강변 골목 산책 → 호텔 체크인 → 약 17:30 저녁 식사 → 예약 시간에 퉈장 야간 유람선 → 약 20:00 호텔 휴식. 실제 미팅 시간은 열차에 맞춰 조정합니다.

2일차 · 고성의 아침과 귀환

호텔 조식 → 약 09:00 퉈장 강변 산책 → 자유시간 → 약 11:30 체크아웃 → 점심 → 열차 시간에 여유를 두고 봉황고성역 이동 → 장가계서역 도착 → 호텔까지 이동. 장가계 호텔 도착으로 일정이 끝납니다. 같은 날 항공편을 연결하려면 이동 여유를 별도로 확인합니다.

포함 사항

왕복 고속철도 2등석, 장가계 호텔과 양쪽 역 이동, 한국어 가이드, 봉황고성 조식 포함 2인실 1박, 첫날 저녁과 둘째 날 점심, 퉈장 야간 유람선·선충원 생가·만수궁 묶음 입장권. 2인 1실이며 홀수 인원의 마지막 1명은 별도 객실을 포함합니다.

별도 비용과 이용 조건

첫날 점심, 표시되지 않은 식사와 음료, 9경 전체 관람권, 여행자보험, 개인경비, 추가 객실과 호텔 업그레이드는 별도입니다. 공휴일에는 해당 객실 요금을 적용합니다. 열차·유람선·관광지는 실제 운영과 예약 가능 여부에 따라 확정합니다. 추가 활동이나 약정 시간을 넘기는 요청은 미리 협의합니다.

단독 출발과 합류 신청

2명부터 단독 출발이 가능합니다. 같은 날짜·코스에 합류를 신청할 수도 있습니다. 유료 참가자 4명 이상과 열차 좌석·가이드·이동·객실이 확보된 뒤 확정합니다. 표시된 절감액은 합류 성립 시의 참고 금액이며 최종 인원에 따른 서면 견적을 안내합니다. 미성립 시 다른 날짜나 단독 요금을 협의합니다. 내 선택에 담는 것은 예약 확정이 아닙니다.
