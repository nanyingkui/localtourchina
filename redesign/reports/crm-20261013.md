# 客户咨询管理 / 고객 문의 관리

入口：https://localtourchina.com/admin.html，使用原管理员邮箱登录。

网站表单自动进入原台账；聊天咨询人工登记。新增客户阶段、负责人、下次跟进、来源、首次回复标记和出发日期。队列优先显示临近出发、已付款和到期跟进记录。

报价金额或币种改变时，数据库保存版本。预约沿用咨询编号，供应商未确认时拒绝标记已预约。付款与服务确认分别记录。韩文接收回复可复制，不会自动对外发送。

当前提醒为后台到期列表；未接入消息推送、聊天自动同步或在线支付。

验证：数据库管理员权限事务内写入、连续两次报价、供应商确认保护均通过，测试记录全部回滚。报价表开启 RLS，anon 无 SELECT 权限。真实管理员登录后的完整浏览器操作尚需邮箱登录后验证，未发送登录邮件或客户消息。

既有安全检查：公开提交和凭令牌查看进度 RPC 为必要接口。移除了 rls_auto_enable 公共执行权限。原认证设置未开启密码泄露保护，本次没有改认证设置，参考 https://supabase.com/docs/guides/auth/password-security#password-strength-and-leaked-password-protection。

고객 단계·담당자·다음 처리 일정·문의 출처를 기록하고 상담번호를 유지한 채 견적과 예약을 관리합니다. 웹 문의는 자동 접수되며 채팅 문의는 담당자가 등록합니다. 관리 화면에서 후속 상담 기한을 확인할 수 있습니다. 외부 알림·채팅 자동 연동·온라인 결제는 아직 연결되지 않았습니다.
